# Desktop controls

Everything here has a pointer path. Keyboard bindings are accelerators.

## Waybar

| Control | Left click | Right click |
|---|---|---|
| Apps | Toggle Rofi application search | — |
| Chrome / Terminal / Files | Launch a new window | — |
| Workspace 1 / 2 | Switch workspace | — |
| Running task | Focus/minimize | — |
| Music note | Toggle music, visualizer, and EQ panel | — |
| Media transport | Previous, play/pause, next | — |
| Media title | Toggle music/EQ panel when a player is active | Play/pause |
| CPU / memory | Open Mission Center | — |
| Volume | Toggle audio panel | Open advanced mixer |
| Wi-Fi | Toggle network panel | Open connection editor |
| Bluetooth | Toggle device panel | Open Blueman |
| Battery | Toggle power panel | Open power menu |
| Clock | Toggle calendar/weather | — |
| Bell | Toggle notification history | Toggle Do Not Disturb |

Clicking the same status control again closes its panel. Clicking outside an
open QuickShell panel dismisses it.

Middle-clicking a running task closes it. Application search follows the usual
Start-menu model: hover to select and single-click to launch.

Open the battery/power panel and click **Wallpapers & colors** to browse the
local collection. Choosing an image changes the background and regenerates the
desktop palette together. The same panel has pointer-accessible region and
full-screen screenshot buttons under **Capture**.

## Optional shortcuts

| Shortcut | Action |
|---|---|
| Super | Toggle Apps |
| Super+Enter | Terminal |
| Super+E | Files |
| Super+B | Browser |
| Super+1 / Super+2 | Switch workspace |
| Super+Shift+1 / Super+Shift+2 | Move window to workspace |
| Super+Space | Toggle floating |
| Super+F | Maximize / restore |
| Super+Shift+F | Fullscreen / restore |
| Alt+F4 | Close |
| Super+L | Lock |
| Super+Shift+S | Region screenshot to file and clipboard |
| Print | Full-screen screenshot to file and clipboard |
| Ctrl+Alt+Delete | Power panel |

Window borders and corners are pointer-resizable. Native application titlebars
remain available; Super+left-drag and Super+right-drag are optional fallbacks.
